# Tuning (validation only)

Built by `scripts/06b_tune.py`: all 48 grid settings, each trained with seeds 42, 43, 44 (144 runs, 16.4 min of training). Every run uses lr 0.01, at most 200 epochs, early stopping with patience 20 on the validation AUROC of `any_onset` and age and sex in the heads; the score is the validation AUROC at the best epoch. Test labels are never loaded. Every run is in `tuning_results.csv`.

Because the same validation patients pick each run's epoch and rank the settings, the best mean AUROC is optimistic; the test set (Phase 7) gives the unbiased number.
